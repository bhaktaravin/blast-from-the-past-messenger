## 🚀 TEST IT NOW (5 minutes)

### 1. Start Server
```bash
cargo run --bin server --features server
```

### 2. Start Web Client
```bash
trunk serve
```

### 3. Test Video Call
Open two browser windows:
- Window 1: http://localhost:8080 (login as user1)
- Window 2: http://localhost:8080 (login as user2)

In Window 1:
- Right-click user2 → "📹 Video Call"
- Video starts immediately!

### 4. Deploy
```bash
git add .
git commit -m "Add Jitsi video calling"
git push
```

AWS Amplify auto-deploys. Done! 🎉
